Jak działa box-shadow

Właściwość CSS box-shadow przyjmuje cztery kluczowe wartości: przesunięcie w poziomie i pionie (gdzie pada cień), rozmycie (jak miękkie są krawędzie) oraz rozprzestrzenienie (jak bardzo cień wykracza poza element). Delikatne, rozmyte cienie o niskiej krycie dają subtelny efekt głębi, popularny w nowoczesnym designie interfejsów.

Jaka wartość krycia sprawdza się najlepiej?

Dla subtelnych, eleganckich cieni sprawdza się zwykle 10-25% krycia — wyższe wartości dają mocniejszy, bardziej dramatyczny efekt.
