Czym jest Base64

Base64 to sposób kodowania danych binarnych (lub tekstu) do postaci bezpiecznego ciągu znaków ASCII — używany m.in. do osadzania obrazków bezpośrednio w kodzie HTML/CSS, przesyłania danych w API czy zapisywania danych w formatach tekstowych jak JSON czy XML, gdzie surowe dane binarne nie są dozwolone.

Kiedy używać kodowania Base64

Przydaje się przy pracy z API, które wymaga przesyłania plików lub obrazków jako tekstu, przy debugowaniu tokenów uwierzytelniających (część standardów jak JWT używa Base64), czy przy szybkim sprawdzeniu zawartości zakodowanego ciągu znaków.

Czy Base64 to szyfrowanie?

Nie — to tylko kodowanie, nie szyfrowanie. Każdy może łatwo zdekodować ciąg Base64 z powrotem do oryginalnej postaci, więc nie nadaje się do ochrony poufnych danych.

Czy mogę zakodować polskie znaki?

Tak — narzędzie poprawnie obsługuje kodowanie UTF-8, więc polskie znaki diakrytyczne (ą, ę, ć, itd.) są kodowane i dekodowane bez utraty danych.
